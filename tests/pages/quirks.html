Quirks mode and the legacy attributes

This page has no doctype, so it is in quirks mode, and it is styled only by attributes the way pages were before stylesheets: the body's text colour and its topmargin, leftmargin and rightmargin — twelve pixels above, twenty-four at the sides — and the font and hr attributes below.

1. A table does not inherit the text around it

This paragraph is centred and set in 13px Verdana, and so is everything else inside the center, except the table.

In quirks mode a table resets the font size, the weight, the style, the line height, the white space and the alignment to their initial values, so this cell's text starts at its left edge and is 16px — still Verdana, because the family is not among them.

Known gaps here: a center should put the table itself in the middle too, which takes the legacy alignment of the blocks inside it; and quirks mode drops the default top margin of the first heading in the body, which is layout's quirk rather than the style sheet's.
